# ADR-001: Role 기반 접근 제어 채택

## 상태
Accepted

## 배경
CILS는 여러 대학 애플리케이션의
접근 권한을 중앙에서 관리해야 한다.

## 결정
사용자별 권한 대신 RBAC를 적용한다.

역할:
- STUDENT
- PROFESSOR
- STAFF
- ADMIN

## 선택 이유
- 권한 관리 구조 단순화
- 신규 애플리케이션 추가 용이
- 역할별 일관된 접근 정책 적용

## 고려 사항
- 동일 Role 사용자에게 동일한
  서비스 접근 정책이 적용됨
- 기존 세션과 토큰에 권한 변경을
  반영하는 정책이 필요함
